# Komentář k zákonu České národní rady č. 334/1992 Sb., o ochraně zemědělského půdního fondu

Otevřený komentář k zákonu o ochraně zemědělského půdního fondu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; zásady ochrany zemědělské půdy, ochrana ZPF při územním plánování a povolování záměrů, odnětí půdy a souhlas s odnětím, odvody a sazebník odvodů, orgány ochrany ZPF, přestupky a přechodná ustanovení.

Konsolidované znění: dokument e-Sbírky `SB-1992-00334_2025-10-01`.
